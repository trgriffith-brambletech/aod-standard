# Overview

AI Orchestrated Development (AOD) is an open software engineering methodology that enables humans and artificial intelligence to collaborate through a structured, governed development lifecycle.

Rather than focusing solely on code generation, AOD emphasizes understanding, governance, architecture, planning, implementation, validation, and continuous evolution.
